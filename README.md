#  Финансовый трекер (консольное приложение)
- Простое и удобное приложение для учёта личных финансов, написанное на Python. 
- Позволяет отслеживать доходы и расходы, управлять сбережениями, настраивать регулярные операции и получать статистику за месяц с графиком распределения по категориям. 
- Все данные хранятся в JSON-файле.

##  Возможности

- Доходы и расходы – добавление операций с указанием суммы, категории.
- Сбережения – отдельный учёт накоплений (пополнения, снятия).
- Регулярные операции – зарплата, коммунальные платежи и другие повторяющиеся транзакции с автоматическим или ручным подтверждением.
- Статистика за месяц – общая сумма доходов и расходов, детализация по категориям, график в консоли.
- Сохранение данных – вся информация хранится в файле finance.json в удобном формате.

##  Требования

- Python 3.6 или выше
- Операционная система: Windows, macOS, Linux

##  Установка и запуск

- Откройте папку FinanceTracker
- Запустите файл python finance_tracker.py
## Данные
- Приложение хранит все данные в файле finance.json в текущей папке.
- В этом репозитории уже есть пример файла (`finance.json`), который вы можете использовать для тестирования или заменить на свой.
- ?? Обратите внимание: так как файл finance.json не исключён из репозитория, он будет публичным, если репозиторий открыт. 
- Убедитесь, что в нём нет личной информации, или добавьте его в .gitignore при необходимости.
